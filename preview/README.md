# TripleScreen Preview

Browser demo of the TripleScreen layout editor and compositor. It does **not** talk to Discord — use it to exercise presets, drag/resize, and `canvas.captureStream()` locally.

```bash
npm install
npm run dev
```

Default URL: [http://127.0.0.1:47321](http://127.0.0.1:47321)

For the real Discord plugin, copy `../src/userplugins/triplescreen` into a Vencord source tree (see the repo root README).
